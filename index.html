YOLO Robustness Lab

Reproducible robustness benchmarking for YOLO object detectors.

Benchmark engine

Python/Ultralytics engine for deterministic transformations, IoU matching, metrics, annotations and machine-readable run artifacts.

pip install -e ".[dev]"

Standard suite

Severity suite

Vercel role

This page is the static dashboard/reporting layer. Run YOLO inference locally, in Docker, or on a GPU host; do not use Vercel serverless functions as the benchmark worker.

Run commands

python -m yolo_robustness benchmark --images data/images --labels data/labels --model yolov8n.pt --output runs/baseline

python -m yolo_robustness benchmark --images data/images --labels data/labels --model yolov8n.pt --output runs/severity --transform-suite severity

python -m yolo_robustness report runs/baseline

Methodology

  • Ground truth comes from independent YOLO-format labels.
  • Each image is evaluated under named deterministic conditions.
  • Predictions are matched to ground truth by IoU threshold.
  • Reports include precision, recall, F1, IoU, confidence and fragmentation.
